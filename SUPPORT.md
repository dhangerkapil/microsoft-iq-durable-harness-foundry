# Support

This is a sample to learn from and adapt, not a supported product. There is no service-level agreement.

- **Questions and bugs:** open a GitHub issue with the steps to reproduce, the script output and the versions of
  PowerShell, Azure CLI, Python and Node.js. Remove tenant IDs, names and URLs from logs first.
- **Security problems:** see [SECURITY.md](SECURITY.md).
- **Product questions about Microsoft Foundry, Microsoft Agent Framework, Work IQ or Microsoft Fabric:** use the
  product documentation and support channels on Microsoft Learn.
